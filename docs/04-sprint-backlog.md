## 4.3 My backend/database work breakdown

These are task groups based on my described contribution.
- **Backend setup and structure:** work in Java and Spring Boot.
- **Registration and security:** implement and troubleshoot registration and Spring Security behaviour.
- **API development:** create or connect REST endpoints for frontend use.
- **Persistence/connectivity:** test MySQL database connectivity and persistence behaviour.
- **Password protection:** test password encryption/hashing behaviour.
- **API testing:** use Postman to test requests, responses and error cases.
- **Integration:** help connect backend functionality to the frontend and investigate integration problems.

## 4.5 Reflection

Breaking the work into phases made it easier to separate idea discovery, requirements, design, frontend development, backend development, testing and deployment. My backend work involved more than writing endpoint code: I also had to investigate security configuration, test API behaviour and check database connectivity. I learned that integration should be checked throughout development rather than left until the end. A key improvement for a future project would be to keep a clear sprint backlog with task owners, acceptance criteria, due dates and links to evidence. Because the exact sprint duration is not confirmed, I have not assigned invented sprint numbers or dates.
